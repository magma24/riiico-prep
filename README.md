# RIIICO Interview Prep

This private repository contains structured mini-projects and math notes to prepare for the 3D Software Engineer role at RIIICO.

## 🎯 Goal

- Develop and implement 3D data processing algorithms
- Explore SOTA reconstruction methods (geometry & AI)
- Build point cloud, computer vision, and volumetric modeling demos
- Solidify math concepts in linear algebra, geometry, and optimization

## 📁 Project Structure
```
riiico-prep/
├── projects/

│ └── volumetric_modeling/ # Voxel grid, TSDF fusion
├── math_notes/ # Notes on geometry, optimization
├── README.md
```
